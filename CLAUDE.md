# Capiflo — capiflo.co.uk

UK SME-finance broker pSEO site. Next.js 16 (App Router, Turbopack, `output: 'standalone'`),
React 19, Tailwind 4, shadcn (primitives live in `src/registry/new-york-v4/ui/`).

**Regulatory position (never violate):** Capiflo is a commercial finance broker, NOT a lender,
and is NOT FCA authorised — it arranges unregulated business lending only. Copy says
"we arrange / we match", never "we lend", and must never imply FCA authorisation.

## Architecture

- ~512 static pages: 71 counties + 388 towns (`/locations`), 15 sectors, 10 funding products
  (hardcoded dirs, no `[slug]`), 8 calculators, 8 guides.
- **Location prose is computed at render time**, not persisted: `townVariants()`
  (`src/lib/seo/entity-variants.ts`) + generators in `src/lib/content-generation/` run inside
  the page components, deterministically (FNV-1a hash of slug — no `Math.random`, ISR-safe).
  `scripts/generate-content.ts` is a validation/dry-run CLI, not a persistence step.
- SEO engine: `src/lib/seo/` — `entity-variants.ts` (Benner slot discipline: URL ≠ title ≠ H1 ≠
  H2s, wiki-variant rotation), `semantic-triples.ts`, `tiering.ts` (A/B/C anti-thin gates →
  sitemap priority), `research-data.ts` (curated PAA/entities).
- Article content: structure in `src/data/{calculators,guides}.ts`, SERP-calibrated bodies in
  `src/content/{calculators,guides}/<slug>.ts` (`ArticleContent` shape), slugs must stay 1:1.
- `src/data/locations/wiki-variants.ts` is GENERATED by `npm run seo:wiki` — never hand-edit.
- Single source of NAP truth: `src/data/business-config.ts`. Placeholder values are gated by
  `hasRealPhone()` / `hasRealAddress()` — pages and JSON-LD hide them rather than ship fakes.
  Fill in real phone/address/companyNumber there and everything lights up site-wide.

## Content pipeline

All content work follows `seo/CONTENT-PIPELINE.md`:
- Location pages → Benner entity method (local-entities-pseo skill): `npm run seo:wiki`,
  slot discipline, true-statement rule (homepage = UK entity; no premises).
- Articles → DataForSEO engine (dataforseo-content-engine skill): `npm run seo:clusters` /
  `seo:serp` / `seo:brief` / `seo:entities` / `seo:density` (wrapped by `scripts/seo/engine.sh`;
  needs `DATAFORSEO_AUTH` in `.env.local`). Research before writing; verify coverage ≥70 after.
- Master strategy brief: `seo/ENTITY-BRIEF.md` (head terms, co-occurrence entities,
  disambiguation traps, slot tables).

## Commands

`npm run dev` / `build` / `type-check` / `lint`. SEO: `seo:research`, `seo:wiki`, `seo:clusters`,
`seo:serp`, `seo:brief`, `seo:entities`, `seo:density`. DataForSEO calls cost credits — brief.mjs
skips existing briefs; don't loop SERP pulls over large lists without confirming.

## Gotchas

- Dev mode only generates 10 town pages (`generateStaticParams` + `dynamicParams=false`) —
  other towns 404 in dev; production builds all.
- Voice gates: no em/en dashes in content, first-person plural broker voice, source-cite figures.
- `/blog` was removed (redirects → `/guides`); don't re-add without a non-overlapping plan.
- Grade content density against the authored strings in `src/content/`, not built `.html`
  (RSC streaming shells contain almost no visible text).
